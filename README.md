# ImageLab

ImageLab is a desktop Image Processing & Enhancement System
developed in Python.

## Features

- Image opening and saving
- Brightness and contrast adjustment
- Image filters
- Saturation and hue adjustment
- RGB channel adjustment
- Gamma correction
- Histogram equalization
- Auto enhancement
- Thresholding
- Image transformation
- Crop and resize
- Undo and redo
- Before/After comparison
- Image analysis
- Image comparison
- Image information
- Batch processing
- Editing presets
- Processing history
- Processing stack
- Configurable settings

## Technologies

- Python
- Tkinter
- Pillow
- NumPy
- Matplotlib
